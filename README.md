# Neon Sentinel

一款以 Three.js 製作的第一人稱 3D 射擊遊戲原型。清除科幻訓練場中的 6 台不同型機器人，並在生命值耗盡前完成任務。

## 操作方式

- **W / A / S / D**：移動
- **滑鼠**：瞄準
- **滑鼠左鍵**：射擊
- **R**：重新裝填 12 發彈匣（備用彈藥無限，約 1.4 秒完成）
- **Esc**：暫停
- 若瀏覽器無法鎖定滑鼠，請按住左鍵拖曳瞄準。

## 功能

- 第一人稱 3D 訓練場與滑鼠瞄準
- 3 種會靠近玩家並造成傷害的機器人：快速但脆弱的偵察型、標準突擊型，以及需要多次命中的重裝型
- 重裝型有 3 點裝甲；命中提示會顯示剩餘裝甲
- 命中時有依敵人類型變色的火花與擴張準星；擊破時有較大的粒子爆散、擊破準星與短暫畫面閃光
- 12 發彈匣、HUD 彈藥數量與換彈進度；備用彈藥無限
- 射擊命中、生命值、擊破數與勝敗提示
- 開始、暫停、繼續與重新開始

## 執行

需要網路連線以載入 Three.js。由專案資料夾啟動本機伺服器：

```powershell
python -m http.server 8000
```

接著在瀏覽器開啟 `http://localhost:8000`。ES module 不支援直接以 `file://` 開啟。
