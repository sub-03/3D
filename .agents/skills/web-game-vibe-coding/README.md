# Web Game Vibe Coding Skill

此資料夾包含一份可供 AI Coding Agent 使用的網頁遊戲開發 Skill。

## 內容

- `SKILL.md`：主要規則與階段式開發流程

## 建議用途

可作為 Codex、Cursor、Claude Code 等 AI Coding Agent 的專案規範或 Skill 基礎。

核心特色：

- 初學者友善
- HTML/CSS/JavaScript 優先
- 遊戲開發分為 7 個 Phase
- 控制 Agent Token、工具呼叫與工作量
- 先完成可玩原型，再投入正式美術
- 優先採用 Kenney、itch.io CC0、OpenGameArt 等免費素材來源
- 素材需記錄授權與來源
